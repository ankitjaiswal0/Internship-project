# Cryptography Algorithms Implementation

## Objective

This project demonstrates core cryptography concepts using Python. It provides a simple command-line toolkit for AES encryption/decryption, RSA key generation, RSA encryption/decryption, and SHA-256 hashing.

## Tools Used

- Python
- cryptography library
- hashlib
- Command Line Interface (CLI)

## Features

- AES encryption and decryption using Fernet
- RSA key generation, encryption, and decryption
- SHA-256 hashing for input strings
- Easy-to-use terminal-based menu interface
- Well-commented code suitable for internship evaluation

## How to Run

1. Open a terminal in the project folder.
2. Create and activate a virtual environment:
   - `python -m venv venv`
   - `venv\Scripts\activate`
3. Install dependencies:
   - `pip install -r requirements.txt`
4. Start the program:
   - `python main.py`
